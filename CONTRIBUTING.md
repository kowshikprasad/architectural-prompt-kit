# Contributing

Thank you for considering a contribution to Architectural Prompt Kit.

## Before you start

- Search existing issues before opening a new one.
- For substantial changes, open an issue first to discuss the proposal.
- Keep changes focused and explain the architectural-visualization use case.

## Development

Requirements: Node.js 20 or newer.

```bash
npm test
```

The project intentionally has no runtime dependencies. Add a dependency only when the benefit is clear and documented.

## Pull requests

A good pull request should:

1. Explain the problem and proposed behavior.
2. Include tests for new or changed behavior.
3. Update the README when public behavior or the prompt format changes.
4. Avoid silently changing the v1.0 prompt format.
5. Keep examples provider-neutral unless an adapter explicitly targets a provider.

By participating, you agree to follow the project Code of Conduct.
