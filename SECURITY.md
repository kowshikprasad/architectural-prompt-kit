# Security Policy

## Supported versions

The latest version on the default branch is currently supported.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Contact the repository owner privately through the security contact method listed on the GitHub profile.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Please allow reasonable time for investigation and a fix before public disclosure.

This package currently performs local data validation and string formatting. It does not make network requests or execute user-provided prompt content.
